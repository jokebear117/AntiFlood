# AntiFlood 완료 조건

기준 구현은 `21f4d5387884653867edea2358dde9b18cedc49b`이다. 기존 서울 침수 재생 제품의 완료 여부를 확인하고, 실제 결함이 있을 때만 수정한다. 새 제품 기능, 물리 모델 교체, 데이터 추가 수집은 범위에 포함하지 않는다. 아래 조건은 라운드 중 변경하거나 삭제하지 않는다.

| ID | 요구 동작 | 확인 방법 |
| --- | --- | --- |
| A1 | README의 프로젝트 주제·동기·시스템 아키텍처·폴더 구조 네 섹션 | 현재 파일과 소스 경로 대조 |
| A2 | 로컬 지형·관측 강우·WCA2D·활성 Tile·OpenMP로 연속 수심 계산 | 기존 서버 준비 상태, 작은 실데이터 영역의 재생 완료, 양수 강우·작업량·스레드와 유한·비음수 수심 및 수량 오차 확인 |
| A3 | 대시보드에서 영역·가정 배수율·스레드·경계 설정과 시작·일시정지·재개·초기화 | UI 연결 코드와 현재 HTTP 경로 실행, 요청 설정 보존 확인 |
| A4 | 계산 프레임·이미지·위치별 수심 조회 및 저장 기록 재열기·설정 재사용 | 완료 실행을 초기화한 뒤 기록·PNG·수심 조회, 저장 설정으로 새 실행 시작 |
| A5 | 서울 동·서 FABDEM 연결 및 지원 범위·입력 제한 유지 | 경도 127도를 가로지르는 실제 격자, 서부 영역 사전 확인과 잘못된 설정 거절 |
| A6 | Windows Launch.cmd가 기본 WSL 환경을 이용하고 준비된 서버 재사용 | 실행 파일 연결 확인 및 `wsl -- sh scripts/launch.sh`의 성공과 서버 PID 유지 |
| A7 | Solar는 선택적 읽기 전용 보조이며 키 없이도 핵심 기능 실행 | 코드의 조회 도구와 키 미설정 응답 확인. 유료 외부 호출은 필수 완료 조건이 아님 |

각 조건의 현재 결과와 근거는 STATE와 HISTORY에 기록한다. 외부 컨트롤러는 DONE 응답만으로 종료하지 않고 별도의 실데이터 검증을 실행한다. 기존 서버가 계산 중이면 이를 중단하지 않고 BLOCKED로 종료한다. 실제 수심 예측 정확도와 침수흔적 비교는 기존 제품의 미검증 한계로 유지한다.
